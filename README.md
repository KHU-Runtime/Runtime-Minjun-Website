# RUNTIME; 홈페이지 (경희대학교 이과대학 IT 동아리 런타임)

HTML, CSS, JavaScript만으로 만든 동아리 홍보용 정적 홈페이지입니다.
설치·빌드 없이 로컬에서 바로 열 수 있습니다. GitHub Pages는 `main` 브랜치의 저장소 루트에서 파일을 게시합니다.

---

## 1. 실행 방법

### 방법 A. 그냥 열기 (가장 간단)
1. zip 파일의 압축을 풉니다.
2. `runtime-homepage` 폴더 안의 **`index.html`** 을 더블클릭하면 브라우저에서 홈 화면이 열립니다.

### 방법 B. VS Code + Live Server (수정하면서 볼 때 추천)
1. VS Code에서 **파일 → 폴더 열기**로 `runtime-homepage` 폴더를 엽니다.
2. 확장(Extensions) 탭에서 **Live Server**(제작자 Ritwick Dey)를 설치합니다.
3. `index.html`에서 마우스 오른쪽 클릭 → **Open with Live Server**.
4. 파일을 저장할 때마다 화면이 자동으로 새로고침됩니다.

> 압축을 풀지 않고 ZIP 안에서 바로 열면 CSS·JS가 적용되지 않을 수 있어요. 꼭 압축을 푼 뒤 여세요.
> 인터넷이 없으면 웹폰트 대신 기본 글꼴로 표시됩니다. 기능은 똑같이 동작해요.

## 2. 화면 구성

메뉴를 누르면 각각 다른 화면(파일)으로 전환 애니메이션 없이 바로 이동합니다.

| 화면 | 파일 | 내용 |
|---|---|---|
| 홈 | `index.html` | 메인 화면 + 동아리 소개·활동·아카이브·런타임의 역사·지원을 간략히 소개하고 각 화면으로 연결 |
| 동아리 소개 | `about.html` | 소개글, 동아리 정보 패널, 핵심 가치 |
| 동아리 활동 | `activity.html` | 기초반(세미나)·심화반·자격증&스터디·공모전 활동 슬라이더, "런타임의 한 학기" 일정 (학기 중 / 방학) |
| 아카이브 | `archive.html` | **런타임의 역사 입구**(누르면 역사 문서로 이동) + **활동 기록**(사진, 분류별 보기, 누르면 사진 크게 보기) |
| └ 런타임의 역사 | `history.html` | 문서 형식. 1기·2기·3기·4기를 누르면 그 기수의 개요·**임원진 소개**·**활동 사진**이 문서로 열림 |
| 동아리 지원 | `recruit.html` | 모집 배너, 인스타그램 공지 / 구글폼 지원서 연결, 모집 대상, 지원 방법 |
| FAQ | `faq.html` | 자주 묻는 질문, 인스타그램 DM 문의 |

하위 화면 아래쪽에는 **이전 / 다음 화면** 버튼이 있어 순서대로 둘러볼 수 있습니다.
상단 메뉴는 영어(ABOUT · ACTIVITY · ARCHIVE · RECRUIT · FAQ)로만 표시되고, 마우스를 올리면 한국어 이름이 말풍선으로 보입니다.

홈 모니터에는 토끼의 타건에 맞춰 코드가 표시됩니다. ‘한 글자 입력’ 버튼이나 홈 첫 화면에서 글자 키를 누르면 직접 진행할 수 있습니다. ‘코드 크게 보기’를 누르면 나오는 코드 창은 VS Code 화면을 본떠 만든 것이고, 코드 색도 VS Code 기본 테마(Dark+)의 색을 그대로 썼습니다. 코드 문장은 `js/main.js`의 `setupTyping` 안 `lines`에서 바꿀 수 있어요.

## 3. 폴더 구조

```
runtime-homepage/
├── index.html, about.html, activity.html, archive.html,
│   history.html, recruit.html, faq.html   ← 화면별 파일
├── css/style.css      ← 디자인 (색상, 레이아웃, 애니메이션, 반응형)
├── js/data.js         ← ★ 내용 설정 파일 (링크, 활동, 일정, 역사, 아카이브, FAQ)
├── js/layout.js       ← 공통 헤더·메뉴·상단 배너·이전/다음 버튼·푸터
├── js/main.js         ← 화면별 동작 (활동 슬라이더, 아카이브, 사진 보기 등)
├── images/logo.png    ← 런타임 로고
├── images/favicon.png ← 브라우저 탭 아이콘
├── images/archive/    ← 아카이브(활동 기록) 사진 폴더
└── images/history/    ← 런타임의 역사(임원진·기수별 활동) 사진 폴더
```

**메뉴 이름·순서, 화면 상단 배너 문구**는 `js/layout.js` 맨 위의 `PAGES`(메뉴 화면)와 `SUBPAGES`(런타임의 역사처럼 메뉴 아래에 속한 화면)에서 바꿉니다.
헤더와 푸터를 여섯 파일에 각각 고칠 필요가 없어요.

## 4. 내용 바꾸기 → `js/data.js`

| 바꿀 것 | `data.js`의 항목 |
|---|---|
| 인스타그램 주소, 구글폼 지원서 주소 | `links` |
| 소개 화면의 동아리 정보 패널 | `profile` |
| 지원 화면의 배너 문구, 모집 대상, 지원 방법 | `recruit` |
| 활동 4가지 (홈 카드 + 활동 화면 슬라이더) | `activities` |
| 활동 일정 제목과 학기 중 / 방학 항목 | `schedule` |
| 런타임의 역사 (기수별 문서: 개요, 임원진, 활동 사진) | `history` |
| 아카이브 분류 이름·색 | `archiveCategories` |
| 아카이브 기록과 사진 | `archive` |
| FAQ | `faq` |

**활동 설명·FAQ 문구, 런타임의 역사(1기~4기의 연도·임원진 이름 OOO·문구), 아카이브 기록 6개는 모두 예시입니다** (노란 "예시" 표시가 붙어 있어요).
실제 내용으로 바꿔 주세요.

### 구글폼 연결
```js
links: {
  instagram: "https://www.instagram.com/khu_runtime/",
  applyForm: "https://forms.gle/xxxxxxxx"
},
```
주소를 넣으면 **지원서 작성하기** 버튼이 켜지고 새 탭으로 구글폼이 열립니다.
비어 있으면 버튼이 회색으로 바뀌고 "지원서 링크 준비 중"이 표시됩니다.

### 활동 일정 바꾸기
```js
schedule: {
  title: "런타임의 한 학기, 이렇게 보내요!",
  periods: [
    { en: "SEMESTER", name: "학기 중", months: "3월 – 6월", items: ["세미나 활동", "MT", "다양한 번개 모임"] },
    { en: "VACATION", name: "방학",   months: "7월 – 8월", items: ["자격증 스터디", "공모전 참여"] }
  ]
}
```
`items`에 항목을 추가하거나 지우면 화면에 그대로 반영됩니다.

## 5. 런타임의 역사 (기수별 문서) 정리하기

아카이브 화면의 **런타임의 역사** 카드를 누르면 `history.html`이 열립니다.
왼쪽(휴대폰에서는 위쪽)의 1기·2기·3기·4기를 누르면 그 기수의 문서가 펼쳐지고, 문서는 다음 세 단락으로 되어 있어요.
각 단락 제목을 누르면 접고 펼 수 있어요.

1. **개요**: 소개 문단 + 주요 활동
2. **임원진 소개**: 회장 · 부회장 · 총무 3명. 카드를 누르면 한마디가 펼쳐짐
3. **활동 사진**: 누르면 크게 보기 (좌우로 넘기기)

내용은 `js/data.js`의 `history`에서 고칩니다. **아카이브의 활동 기록과는 따로** 관리돼요.

```js
{
  gen: "4기", year: "2026", period: "2026.03 – 2027.02",
  slogan: "지금의 런타임",
  intro: "지금 활동 중인 기수예요. ...",
  highlights: ["기초반 · 심화반 · 자격증 스터디 운영", "MT와 다양한 번개 모임"],
  executives: [
    { role: "회장",   name: "홍길동", info: "물리학과 · 25학번", comment: "한마디", photo: "images/history/4기-회장.jpg" },
    { role: "부회장", name: "...", ... },
    { role: "총무",   name: "...", ... }
  ],
  photos: [
    { src: "images/history/4기-mt.jpg", caption: "4기 MT" }
  ]
}
```

- 새 기수는 목록 **맨 아래**에 추가하세요. 마지막 기수에 **NOW** 표시가 붙고, 화면을 열면 마지막 기수 문서가 먼저 보여요.
- 임원진 사진(`photo`)이 비어 있으면 직책 첫 글자가 들어간 동그라미가 대신 표시돼요.
- 활동 사진 `src`가 비어 있으면 "사진 준비 중" 그림이 표시돼요.
- `history.html#gen-2`처럼 주소 뒤에 붙이면 2기 문서가 바로 열려요.
- 임원진 이름·사진은 개인정보이니, 홈페이지에 올리기 전에 본인 동의를 받아 주세요.

## 6. 아카이브에 활동 · 사진 추가하기

1. 사진을 `images/archive/` 폴더에 넣습니다. (예: `2026-mt-1.jpg`)
2. `js/data.js`의 `archive` 목록 **맨 위**에 기록을 추가합니다.

```js
{ id: "2026-mt", category: "mt", date: "2026.05", title: "1학기 MT",
  desc: "부원들과 함께 MT를 다녀왔어요.",
  images: ["images/archive/2026-mt-1.jpg", "images/archive/2026-mt-2.jpg"] },
```

- `id`: 기록마다 다른 영어 이름 (홈에서 카드를 누르면 이 기록이 바로 열려요)
- `category`: `seminar`(세미나) · `mt`(MT) · `meetup`(번개 모임) · `study`(스터디) · `contest`(공모전)
- `images`: 여러 장 넣으면 사진 보기 창에서 좌우로 넘겨 볼 수 있어요. 비워 두면 "사진 준비 중" 그림이 표시됩니다.
- 사진 경로가 틀려도 화면이 깨지지 않고 "사진 준비 중" 그림으로 대신 표시됩니다.
- 예시 기록은 `sample: true`가 붙어 있어요. 실제 기록으로 바꾸면 지우거나 기록째 삭제하세요.
- 홈 화면에는 목록 위에서부터 4개가 표시됩니다.

## 7. 색상 (클래식 블루 팔레트)

공통 블루는 `#304FA7`, 연보라는 `#E1DDFF`, 카드 배경은 흰색입니다. 공통 색상과 홈 레이아웃은 `css/style.css`의 **밝은 블루와 라벤더** 주석 아래에서 수정할 수 있어요. 토끼와 모니터 그림은 `images/cat-*.png`, 타건 동작과 화면 코드는 `js/cat-studio.js`에 있습니다.

활동 4가지와 아카이브 분류 색은 `js/data.js`의 `color`에 있고, 모두 같은 남색 계열의 진하기 단계로 맞춰 두었어요.
